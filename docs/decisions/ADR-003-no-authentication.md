# ADR-003: 로그인·회원가입 기능 미구현

- **날짜:** 2025-05
- **상태:** 채택됨

## 결정

이 서비스는 회원가입·로그인 기능을 제공하지 않는다. 모든 API는 인증 없이 접근 가능하다(`AllowAny`).

## 이유

- 서비스의 핵심 가치는 도서 추천, 리뷰 열람, 서점 가격 비교, 도서관 위치 확인이다.
- 이 기능들은 로그인 없이도 제공 가능하며, 프로젝트 개발기간이 한정적이라 인증 시스템 구현보다는 핵심 기능에 집중해야한다.
- 리뷰 작성은 방명록 형태로, 닉네임만 입력하는 방식으로 구현한다.

## 고려했던 대안

| 대안 | 포기 이유 |
|---|---|
| JWT 기반 인증 | 구현 복잡도와 개발 일정 고려 시 우선순위 낮음 |
| 소셜 로그인(OAuth) | 외부 서비스 연동 필요, 핵심 기능 개발에 집중하기로 결정 |

## 영향

- `config/settings.py`의 `DEFAULT_AUTHENTICATION_CLASSES`를 빈 값으로 유지한다.
- `DEFAULT_PERMISSION_CLASSES`는 `AllowAny`로 설정한다.
- 추후 인증이 필요해지면 이 ADR을 갱신하고 별도 ADR을 작성한다.
