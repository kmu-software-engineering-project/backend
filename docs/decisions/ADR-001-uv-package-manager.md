# ADR-001: 패키지 관리자로 uv 채택

- **날짜:** 2025-05
- **상태:** 채택됨

## 결정

Python 패키지 관리자로 `pip` 대신 `uv`를 사용한다.

## 이유

- `pip`은 의존성 설치 속도가 느리고, lock 파일 관리가 별도 도구(pip-tools 등) 없이 불가능하다.
- `uv`는 Rust 기반으로 pip 대비 10~100배 빠르며, `uv.lock`으로 재현 가능한 환경을 보장한다.
- `uv sync --dev`로 운영/개발 의존성을 한 번에 설치할 수 있어 CI 설정이 단순해진다.
- 이전 프로젝트에서 uv를 적용하여 사용한적이 있다.

## 고려했던 대안

| 대안 | 포기 이유 |
|---|---|
| `pip` + `requirements.txt` | lock 파일 없어 환경 재현이 불안정 |
| `pip` + `pip-tools` | 도구가 두 개로 늘어나 관리 복잡도 증가 |
| `poetry` | 기능은 유사하나 uv가 더 빠르고 Django 프로젝트에서 설정이 단순 |

## 영향

- 패키지 추가: `uv add {패키지명}` (pip install 사용 금지)
- 의존성 설치: `uv sync --dev`
- 스크립트 실행: `uv run python manage.py ...`
- `uv.lock` 파일은 git에 커밋하며 직접 수정하지 않는다.
